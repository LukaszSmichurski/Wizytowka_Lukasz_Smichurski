📈 Fintech Portfolio & Strategy Dashboard

Quantitative Strategy Automation & Analysis

Zobacz aplikację
An interactive web application for portfolio analysis, financial instrument return comparison, and quantitative strategy automation (Dual Momentum / GEM).

About the Project

This project was created for modern investors looking for tools based on hard data and proven quantitative strategies. The application combines clean software architecture with advanced visualization of real-time market data fetched from Yahoo Finance.

Key Features:
  • Two Analysis Modes: Custom Portfolio (compare any stock indices, equities, or cryptocurrencies) & GEM Strategy (Gary Antonacci's Dual Momentum in Original and European UCITS ETF variants).
  • Automatic Normalization: Recalculating historical valuations to a base of 100, enabling reliable comparisons of growth dynamics across different assets.
  • Professional UI/UX: KPI tiles with dynamic profit/loss coloring, a dark theme for Plotly charts, and a responsive Streamlit layout with a sidebar.

Project Architecture

The project is designed following the Separation of Concerns principle:

Stock_Market_App/
├── app.py              # Main UI presentation layer (Streamlit)
├── logic.py            # Business logic, time-series processing, API
├── config.py           # Asset dictionaries (Indices, US & UCITS ETFs)
├── requirements.txt    # Project dependencies
└── .gitignore          # Files ignored by Git
Tech Stack: Python 3.10+ Streamlit Pandas NumPy Plotly Express yfinance Git / GitHub
