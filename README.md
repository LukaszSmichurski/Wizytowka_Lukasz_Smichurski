# moja_strona

Prosty statyczny serwis osobisty dla Łukasza Śmichurskiego.

Co zawiera:
- `index.html`, `korepetycje.html`, `portfolio.html`
- `css/styles.css` — skonsolidowane style
- `js/scripts.js` — wspólne skrypty (menu, FAQ, reveal, tilt, parallax)

Szybkie instrukcje

1. Otwórz `index.html` lokalnie lub deploy na statycznym hostingu (Netlify, Vercel, GitHub Pages).
2. Zamień `Sitemap` i `robots.txt` domeny `example.com` na Twoją domenę.
3. Wymień `favicon.svg` i `favicon-192.png` na zoptymalizowane ikony dla lepszego wyglądu.

Sugestie:
- Konwertuj tła do `webp` aby przyspieszyć ładowanie.
- Dodaj prosty formularz kontaktowy (Formspree/Netlify Forms) jeśli chcesz odbierać wiadomości.
